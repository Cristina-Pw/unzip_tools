 unzip_tool
This is a useful unzip tool which can unzip plenty zip files autoly.Double click 批量解压工具.exe to launch it.
If the zip files need passwords to unzip,you should make sure that they have the same password,or this tool cannot unzip them autoly.
Before using,you should make sure that WinRAR is already installed in your computer.Input"py -m pip install rarfile py7zr" in powershell to install the dependenciese.
